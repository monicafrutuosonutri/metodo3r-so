# Métricas

Captura de desempenho real por conteúdo. Sem isso, o sistema produz no escuro.

Dados prioritários por post: visualizações, alcance, tempo médio/retenção, salvamentos,
compartilhamentos, comentários, seguidores ganhos.

**Pendente de decisão:** se a captura será manual, exportada do Instagram ou automatizada.
Enquanto não houver método definido, esta pasta fica vazia — e isso é um blocker registrado.
