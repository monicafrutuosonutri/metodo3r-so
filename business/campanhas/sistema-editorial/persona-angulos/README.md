# Persona e Ângulos

Banco de ângulos da persona e banco de linguagem da audiência. É a matéria-prima de todo conteúdo.

Duas coisas diferentes moram aqui:

- **Banco de ângulos** — combinações de dor, situação concreta, pensamento, comportamento, custo, desejo, objeção e mecanismo
- **Banco de linguagem** — palavras reais da audiência: comentários, DMs, caixinhas, perguntas

O banco de linguagem só cresce com material real capturado. Nunca com suposição da criadora.
